## Explicacion profunda de los cambios

Se actualizo `README.md` para que, al ingresar al repositorio, se vea una presentacion clara del producto actual y no el texto historico del alcance anterior.

El nuevo README toma como fuente `Alcance.pdf` y conserva solo las secciones solicitadas: caratula del documento, resumen ejecutivo, vision del producto y alcance del MVP simplificado. Se omitieron requerimientos, endpoints, backlog y trazabilidad para mantener la pagina principal enfocada.

Tambien se elimino del README la mencion anterior a profesores como parte del flujo activo, porque ese modulo quedo fuera del MVP simplificado junto con clases, canchas y reservas.
