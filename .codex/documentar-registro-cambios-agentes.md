# Documentar registro de cambios para agentes

- Fecha: 2026-08-04
- Titulo del PR: Documentar registro de cambios para agentes
- Descripcion de los cambios: Se agrego en `AGENTS.md` la regla de crear un archivo de contexto en `.codex/` por cada cambio realizado en el repositorio.
- Documentos relacionados: `AGENTS.md`
- Autor: Codex

## Explicacion profunda de los cambios

Se incorporo una seccion nueva llamada "Registro de Cambios para Agentes" en `AGENTS.md`.

La seccion indica que, ante cualquier cambio del repositorio, se debe crear un archivo dentro de `.codex/` usando el titulo o nombre del PR como base del nombre del archivo. Tambien define el formato obligatorio de la nota: fecha, titulo del PR, descripcion breve, documentos relacionados, autor y una explicacion profunda de los cambios.

Esta nota en `.codex/` registra el propio cambio de documentacion para que futuros agentes tengan un primer ejemplo de la convencion esperada.
